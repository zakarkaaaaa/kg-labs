# Лабораторная работа №3 — базовые растровые алгоритмы

Интерактивное веб-приложение, которое показывает, как непрерывные отрезки и окружности
превращаются в пиксели. Реализованы пошаговый алгоритм, ЦДА, Брезенхем для отрезка и
окружности, а также сглаживание Ву (дополнительное задание).

## Стек

- React 19 + TypeScript 6 + Vite 8
- Canvas 2D (с учётом `devicePixelRatio`), без сторонних графических библиотек
- Tailwind CSS 4 + собственные CSS-токены, локальные шрифты Inter / JetBrains Mono
- Node.js 24 — замеры производительности и автотесты
- Typst — отчёт `report.pdf`

## Запуск

```bash
npm install
npm run dev       # http://localhost:5174
npm run build     # сборка в dist/
npm run preview   # предпросмотр сборки
```

## Скрипты

| Команда | Что делает |
| --- | --- |
| `npm run verify` | 52 000+ проверок корректности растровых алгоритмов |
| `npm run bench` | замеры в Node, пишет `bench.json` и `bench.md` |
| `npm run example` | пересчитывает примеры для отчёта в `examples.json` |
| `npm run report` | собирает `report.pdf` из `report.typ` |
| `npm run screenshots` | снимает скриншоты интерфейса (нужен запущенный preview на :4174) |

## Что внутри

- `src/core/` — чистые реализации алгоритмов: шаги, решающие переменные, пиксели.
- `src/lib/draw.ts` — отрисовка сетки, осей, пикселей и маркеров на Canvas.
- `src/components/` — визуализатор, инспектор параметров, док с вычислениями, бенчмарк и теория.
- `scripts/` — тесты, замеры, генерация примеров и скриншотов.

## Координатная привязка

Пиксель `(x; y)` — это клетка `[x − 0,5; x + 0,5) × [y − 0,5; y + 0,5)`, её центр совпадает
с узлом сетки. Ось Y направлена вверх; на экране `sx = W/2 + (x − cx)·s`,
`sy = H/2 − (y − cy)·s`. Подробнее — во вкладке «Теория» и в отчёте.
